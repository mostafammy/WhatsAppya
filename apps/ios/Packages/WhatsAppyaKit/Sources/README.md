# Sources

## Overview
Swift package source targets for `WhatsAppyaKit`, separating platform-independent chat parsing/domain logic (`WhatsAppyaCore`) from SwiftUI presentation components and design tokens (`WhatsAppyaUI`).

## Subdirectories & Boundaries
- `WhatsAppyaCore`: [./WhatsAppyaCore/README.md](./WhatsAppyaCore/README.md) - Platform-independent Swift core library (`Application`, `Domain`, `Parsers`, `Pipeline`, `Ports`).
- `WhatsAppyaUI`: [./WhatsAppyaUI/README.md](./WhatsAppyaUI/README.md) - SwiftUI UI components (`Components`) and generated design tokens (`Tokens`).
