# WhatsAppyaUI

## Overview
SwiftUI design system and UI component target for `WhatsAppyaKit`, grouping design tokens and reusable chat presentation components.

## Subdirectories & Boundaries
- `Components`: [./Components/README.md](./Components/README.md) - SwiftUI components (`MessageBubble`, `VoiceNotePlayer`, `StickerView`, `ChatTimeline`).
- `Tokens`: [./Tokens/README.md](./Tokens/README.md) - Generated Swift design tokens namespace placeholder (`WATokens`), replaced by `pnpm tokens` output from `@whatsappya/design-tokens`.
