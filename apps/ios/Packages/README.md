# Packages

## Overview
Local Swift Package dependencies consumed by the `WhatsAppya` iOS application and `ShareExtension` targets.

## Subdirectories & Boundaries
- `WhatsAppyaKit`: [./WhatsAppyaKit/README.md](./WhatsAppyaKit/README.md) - Swift Package Manager package exposing `WhatsAppyaCore` (Foundation-only core library) and `WhatsAppyaUI` (SwiftUI components and tokens).
