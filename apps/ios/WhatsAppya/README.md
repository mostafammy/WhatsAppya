# WhatsAppya

## Overview
Main iOS SwiftUI application target for WhatsAppya, grouping the app lifecycle/navigation root (`App`) and feature-sliced views (`Features`).

## Subdirectories & Boundaries
- `App`: [./App/README.md](./App/README.md) - SwiftUI `@main` entrypoint (`WhatsAppyaApp`) and `NavigationStack` root (`RootView`).
- `Features`: [./Features/README.md](./Features/README.md) - Feature views (`ChatViewer`, `Import`, `Stats`).
