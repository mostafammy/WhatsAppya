# Assets

## Overview
Static frontend templates, client-side media interaction controllers, and bundled animation libraries copied or interpolated into exported WhatsApp HTML chat archives. This package provides the HTML document shell (`template.html`), the interactive media modal, sticker playback controllers, and the hybrid WebAudio/HTML5 `<audio>` voice-note playback and pre-warming engine (`script.js`), alongside the bundled Lottie-web runtime (`lottie.min.js`).

## Interface
- `[assets/script.js:window.openMedia]`: Global function `window.openMedia(src, type)` that opens `#mediaModal` and renders an `<img>` (`type === 'image'`) or `<video>` (`type === 'video'`) inside `#modalContent`.
- `[assets/script.js:window.closeModal]`: Global function `window.closeModal()` that hides `#mediaModal`, clears `#modalContent.innerHTML`, and resets `document.body.style.overflow` to `'auto'`.
- `[assets/script.js:window.replaySticker]`: Global function `window.replaySticker(containerEl)` that triggers `navigator.vibrate(10)`, toggles the `.sticker-bounce` CSS animation, and restarts either a Lottie instance (`.lottie-sticker._lottieAnim`) or a cache-busted animated WebP (`img.src` with `?replay=<timestamp>`).
- `[assets/script.js:window.__WA_VOICE_CACHE__]`: Global object map `window.__WA_VOICE_CACHE__[src]` consumed by `InstantAudioEngine.prototype.loadAudioBytes` to read base64-encoded audio payloads loaded from `_voice_cache/<src>.js` scripts.
- `[assets/script.js:InstantAudioEngine]`: IIFE-scoped engine class (instantiated as singleton `engine`) providing `getAudioContext()`, `initHardwarePrearm()`, `initViewportObserver()`, `observe(playerEl)`, `loadAudioBytes(src)`, `storeByteCache(src, bytes)`, `armAudioElement(playerEl, mediaUrl, startOffset)`, `decodePcm(src, bytes, playerEl)`, and `prewarm(src, playerEl)`.
- `[assets/script.js:VoicePlayerInstance]`: IIFE-scoped controller class attached to each `.apple-voice-player` DOM node as `player._voiceInstance`, providing `initCanvasDpi()`, `onBufferDecoded(buffer)`, `render()`, `togglePlay()`, `play()`, `startWebAudioPlayback(buffer)`, `startHtml5Playback()`, `pause()`, `onPlaybackEnded()`, `startProgressLoop()`, `scrubTo(clientX)`, `cycleSpeed()`, and `attachEvents()`.
- `[assets/template.html:{title}]`, `[assets/template.html:{chat_name}]`, `[assets/template.html:{message_count}]`, `[assets/template.html:{messages}]`: HTML template interpolation placeholders along with `#mediaModal`, `#modalContent`, `style.css` link, and `script.js` script tag.
- `[assets/lottie.min.js:globalThis.lottie]`: UMD module exporting the Lottie animation library (`module.exports`, AMD `define`, or `globalThis.lottie`) with methods `loadAnimation`, `registerAnimation`, `play`, `pause`, `stop`, `togglePause`, `setSpeed`, `setDirection`, `searchAnimations`, `resize`, `goToAndStop`, `destroy`, `freeze`, `unfreeze`, `setVolume`, `mute`, `unmute`, and `getRegisteredAnimations` (`[assets/lottie.min.js:$]`).

## Invariants
- `[assets/script.js:InstantAudioEngine.MAX_CACHE_BYTES]`: Decoded Float32 PCM `AudioBuffer` cache (`this.pcmCache`) is strictly bounded to 48 MB (`48 * 1024 * 1024` bytes), evicting the oldest cached `AudioBuffer` in `decodePcm` when exceeded.
- `[assets/script.js:InstantAudioEngine.storeByteCache]`: Raw `Uint8Array` audio cache (`this.byteCache`) is bounded to at most 24 entries (evicting the oldest entry when `this.byteCache.size >= 24`).
- `[assets/script.js:InstantAudioEngine.MAX_WARM_AUDIO_ELEMENTS]`: Active pooled `HTMLAudioElement`s (`this.warmAudioPool`) are bounded to at most 12 elements; `armAudioElement` evicts and resets the oldest non-playing `<audio>` element when full.
- `[assets/script.js:InstantAudioEngine.initViewportObserver]`: Viewport pre-warming uses a 600px vertical `rootMargin` (`'600px 0px 600px 0px'`) and requires a 90ms intersection dwell timeout (`playerEl._dwellTimer`) before triggering `prewarm(src, playerEl)` and unobserving the element.
- `[assets/script.js:analyzePcmBuffer]`: Leading-silence detection scans up to 0.75s in 5ms windows against a 0.015 amplitude threshold (~-36 dBFS), steps back 25ms, and clamps `voiceStartOffset` to `[0, 0.65]` seconds (applied only when `duration > 1.0`s; default fallback offset is `0.18`s in `[assets/script.js:VoicePlayerInstance]`).
- `[assets/script.js:analyzePcmBuffer]`: Acoustic waveform extraction always computes exactly 36 bars (`numBars = 36`) normalized to the range `[0.15, 1.0]`, matching the 36 deterministic pseudo-random initial bars generated by `seedRandom(this.title)` in `[assets/script.js:VoicePlayerInstance]`.
- `[assets/script.js:VoicePlayerInstance.play]`: At most one `VoicePlayerInstance` can be active at a time (`engine.activeInstance` singleton invariant; calling `play()` pauses any previously active instance).
- `[assets/script.js:VoicePlayerInstance.speeds]`: Playback rate cycles strictly through `[1.0, 1.5, 2.0]` in `cycleSpeed()`, and duration label display mode (`this.timeDisplayMode`) cycles through `'elapsed'` -> `'remaining'` -> `'total'` -> `'elapsed'`.

## Side Effects
- `[assets/script.js:initAll]`: Runs on `DOMContentLoaded` (or immediately if `document.readyState !== 'loading'`) to query and hydrate all `.apple-voice-player`, `.lottie-sticker` (reading JSON from `#data_<id>`), and `.sticker-container` elements.
- `[assets/script.js:InstantAudioEngine.initHardwarePrearm]`: Attaches capture-phase passive `window` listeners for `pointerdown`, `touchstart`, and `keydown` that instantiate and `resume()` the shared `AudioContext` on first user interaction.
- `[assets/script.js:InstantAudioEngine.loadAudioBytes]`: Dynamically injects `<script src="_voice_cache/<src>.js" async>` into `document.head` (removing it on load/error), deletes consumed entries from `window.__WA_VOICE_CACHE__`, and falls back to network `fetch(src, { cache: 'force-cache' })` on error.
- `[assets/script.js:InstantAudioEngine.prewarm]`: Creates persistent `blob:` URLs via `URL.createObjectURL(new Blob([bytes], { type: 'audio/ogg; codecs=opus' }))` cached in `this.blobUrlCache`, mutates `<audio>` attributes/properties (`src`, `preload`, `currentTime`), and invokes `audioEl.load()`.
- `[assets/script.js:VoicePlayerInstance.attachEvents]`: Registers DOM, pointer capture (`setPointerCapture`/`releasePointerCapture`), `requestAnimationFrame` (`startProgressLoop`), and `matchMedia('(prefers-color-scheme: dark)')` listeners; mutates canvas 2D context, DOM classes/styles, WebAudio `BufferSourceNode`s, and triggers device vibration via `navigator.vibrate(8)` (`[assets/script.js:VoicePlayerInstance.play]`) and `navigator.vibrate(10)` (`[assets/script.js:window.replaySticker]`).
- `[assets/script.js:document.addEventListener('keydown')]`: Global `document` `keydown` listener closes `#mediaModal` on `'Escape'` and toggles play/pause on `engine.activeInstance` when `' '` (Space) is pressed with `document.activeElement === document.body`.
