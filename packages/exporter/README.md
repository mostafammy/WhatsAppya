# `@whatsappya/exporter`

## Overview
Self-contained, offline single-file HTML archive exporter package (`@whatsappya/exporter`) built atop `@whatsappya/core` domain types.

## Subdirectories & Boundaries
- `src`: [Exporter Source](./src/README.md) — Exports `StandaloneHtmlExporter` and `ExportAssets` for serializing a `ChatSession` with embedded viewer scripts and CSS into a standalone HTML document.
