# Navigation components

Custom elements powering Multi-Tier Curricular Mode (`Blocks › Subjects › Chapters`):

| Element | Responsibility |
|---|---|
| `<wa-split-view>` | Cupertino three-column navigation split-view (Blocks → Subjects → Chapters + active chat canvas) with collapsible sidebar and keyboard navigation |
| `<wa-breadcrumbs>` | Hierarchical interactive breadcrumb bar showing the active `Block › Subject › Chapter` path with jump-back selection |
