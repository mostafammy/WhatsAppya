# `@whatsappya/viewer`

## Overview
Framework-free Web Components chat viewer package (`@whatsappya/viewer`) providing custom element registrations, component contracts, and generated design-token CSS integration.

## Subdirectories & Boundaries
- `src`: [Source](./src/README.md) — Exports the `VIEWER_ELEMENTS` custom element tag tuple and groups component specs (`./src/components/README.md`) and design-token style guidelines (`./src/styles/README.md`).
