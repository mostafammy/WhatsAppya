# `@whatsappya/platform-web`

## Overview
Browser platform adapter package (`@whatsappya/platform-web`) implementing `@whatsappya/core` ports for client-side zip ingestion, Web Share Target integration, and local OPFS persistence.

## Subdirectories & Boundaries
- `src`: [Platform Web Source](./src/README.md) — Exports `ZipFileSource` (`./src/zip/README.md`) and defines planned Web Share Target (`./src/share-target/README.md`) and OPFS storage (`./src/storage/README.md`) boundaries.
